# Smart Phone Cleaner - Landing Page 🚀

A modern, stunning landing page built with React.js featuring advanced 3D effects, glassmorphism, and liquid animations inspired by Apple and Google's premium design language.

## ✨ Features

- **3D Phone Mockup** - Interactive 3D phone model using Three.js and React Three Fiber
- **Glassmorphism Effects** - Beautiful frosted glass UI components
- **Smooth Animations** - Powered by Framer Motion for buttery smooth transitions
- **Particle Background** - Animated particle system with connecting lines
- **Liquid Blob Animations** - Organic gradient blobs with morphing animations
- **Responsive Design** - Fully responsive across all devices
- **Modern Stack** - Built with latest React 18 and cutting-edge libraries

## 🎨 Design Highlights

- Premium gradient color schemes
- Floating cards with depth and shadows
- Smooth scroll animations
- Interactive hover effects
- Custom scrollbar styling
- Mobile-optimized layouts

## 🛠️ Tech Stack

- **React 18** - Latest React with hooks
- **Framer Motion** - Animation library
- **Three.js** - 3D graphics
- **@react-three/fiber** - React renderer for Three.js
- **@react-three/drei** - Useful helpers for React Three Fiber
- **React Intersection Observer** - Scroll-based animations

## 📦 Installation

```bash
npm install
```

## 🚀 Development

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view in your browser.

## 🏗️ Build

```bash
npm run build
```

Builds the app for production to the `build` folder.
